# Quick Notes (Rainbow Burst)

This project is a lightweight React notes app with a playful Rainbow Burst theme.

- Sidebar with search/filter
- Create, edit, delete notes
- Debounced autosave
- Supabase (if configured) or localStorage fallback
- Accessible UI and toasts

See README_NOTES_APP.md for detailed setup and usage.

## Scripts

- npm start
- npm test
- npm run build
